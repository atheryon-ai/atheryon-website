## H — High

### H1. Deployed /ma/* pages show the CM footer + Terry's LinkedIn
Prod **and** test render the Capital Markets footer (System / Themes / Roadmap / Labs / Writing / About / Contact) and `linkedin.com/in/terencetsakiris` on `/ma/contact` — the nav is correctly M&A, the footer is not. Local code is correct (`Footer.tsx` mode="ma" → `site.footer.maLinks`, `maLinkedin: ''` suppresses LinkedIn), and local `main` == `origin/main` (0e30d06). So either the working tree has uncommitted changes on those files, or the last main deploy is stale/failed.
**Action:** `git status`; check the Actions run for 0e30d06; redeploy and re-verify `/ma/contact` footer. Anna's practice pages currently carry Terry's personal LinkedIn — the exact thing the `maLinkedin` comment forbids.

### H2. /offers/prompts/thanks welcomes buyers to the wrong product
Banner renders `site.pages.mibInsightThanks`: "Welcome to the MiB Insight Program … 15-minute Foundations module". §01 below says "Your Front Office bundle access has been confirmed." A $14,000 Front Office bundle buyer lands on a page headlined for a different (legacy) program.
**Action:** rewrite `mibInsightThanks` (site.ts:31–36) as Front Office bundle copy, or rename the key and neutralise the headline. Terms' "MiB Insight" trademark mention (terms/page.tsx:85) stays only if that name is still sold.

## M — Medium

### M1. Agent runtime contradiction: Claude vs Azure OpenAI
- /system §05: "Claude (Anthropic) as the agent runtime" (site.ts:736); /system §03 "agents run on Anthropic's Claude" (site.ts:696); homepage strip "Powered by Claude"; whole blog post on choosing Claude.
- /ma/approach §04: "**Azure OpenAI** as the agent runtime" (site.ts:1162) — directly after §02 claims "The same partner stack that runs Atheryon's capital-markets practice runs the M&A data work — shared infrastructure, shared directorial archive."
**Action:** if M&A genuinely runs Azure OpenAI, say so explicitly as a difference; otherwise change site.ts:1162 to Claude.

### M2. /labs "See it live" is circular; hero CTAs are dead copy
- Closing CTA (site.ts:243) "See it live" → `https://www.atheryon.com.au` — the reader is already on atheryon.com.au. Should be `https://labs.atheryon.ai`.
- Evidence stat (site.ts:86) "Live — at atheryon.com.au": the platform lives at labs.atheryon.ai; the stat undersells it.
- `labs.hero.primaryCta` ("See it live" → labs.atheryon.ai) and `tertiaryCta` (site.ts:45–46) are never rendered — `DocBanner` takes label/title/body only. Dead copy or missing UI.

### M3. sitemap.xml + llms.txt omit the blog
`/blog` and `/blog/why-claude` (live since 19 May 2026) are absent from `public/sitemap.xml`; `/ma/contact` also absent. `llms.txt` omits Writing too, and describes /labs as "research themes and tooling" — it's the flagship platform sales page.
**Action:** add 3 sitemap entries; add Writing to llms.txt; reword the /labs line.

### M4. AU/US spelling split in visible copy
| Variant | Where |
|---|---|
| judgment | site.ts:149 ("Why banking judgment matters"), 377 ("architecture judgment matters most") |
| judgement | site.ts:151, 182 |
| artefact ×7 | site.ts (labs + M&A copy) |
| artifact | "Proof artifacts" title (site.ts:740), "explainability artifacts" (846), "Artifact types" label (offers/prompts page), blog dek |
| Productized | site.ts:328 (bundle badge, /offers/prompts) |

| Programs | site.ts:377 — title sits directly above bullets using "programme" (379, 383) |

**Action:** pick one dialect (site is otherwise AU: modelled, organisation, licence) and sweep. The site.ts:377 title vs its own bullets is the most visible clash.

### M5. Theme CTAs pass topics the contact form doesn't know
`/themes/[id]` CTA → `/contact?topic=<theme.id>` (7 ids: front-office-trading … foundation-ods). `TOPIC_LABELS` in `ContactForm.tsx:15–24` has none of them, so no message prefill (raw id still posts via hidden field). The comment says "Keep in sync with … any page-level CTA query params."
**Action:** add the 7 theme ids to `TOPIC_LABELS`.

### M6. Two conflicting credibility framings coexist
- /about + llms.txt: lineage = Goldman Sachs, Credit Suisse, Barclays Capital, "**not claims of employment** or system ownership"; HomeStrip renders those three as logo-style marks.
- /labs bio (site.ts:154): "**At Credit Suisse I built** … **At Commonwealth Bank I owned** … At Westpac …" — first-person employment claims over a different institution set (CS, CBA, Westpac).
Both can be true (firm framing vs Terry's personal bio) but a diligence reader will notice the two lists and the disclaimer sitting next to explicit claims.
**Action:** deliberate decision + one line on /labs distinguishing personal history from firm lineage, or align the institution lists.
